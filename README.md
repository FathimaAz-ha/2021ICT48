# [2021ICT48] — Body-site specificity in the human microbiome

## Question
Can unsupervised clustering of 16S rRNA profiles recover human body-site identity,
and which body sites are hardest to distinguish?

## Data
Human Microbiome Project 16S rRNA V1-V3 data via the `MicrobeDS` R package
(`HMPv13` object): 3,285 samples, 15 body sites.
